# Differences between a replayed case and a live cluster that are known and written down in
# docs/design-case.md §8. A command that differs, or that both refuse in other words, fails the sweep
# unless a line here excuses that very difference:
#
#   <verb> [<kind, a pattern>] :: <a pattern the difference must show>
#
# The pattern is what keeps a line from excusing more than it names: `describe secret` is excused for
# counting other bytes, and not for failing.

# It reads the cluster's OpenAPI document, which a case does not carry.
explain :: ^exit codes live 0, frozen 1, live 0
# It prints the address of the server, and a case is served from another one. (Some builds of
# kubectl colour the line, v1.31's among them, and others do not.)
cluster-info :: control plane(\x1b\[0m)? is running at
# A Secret that `freeze` blanked has the marker for every value, so `describe` counts the marker's bytes.
describe secrets? :: \d+ bytes \| frozen: .*\d+ bytes
