# Getting help

- **How to use it:** the docs at [lapilli.dev/docs](https://lapilli.dev/docs/),
  and `lapilli COMMAND --help`.
- **A question:** [Discussions, Q&A](https://github.com/lapilli-project/lapilli/discussions/categories/q-a), where
  others can answer too, and the next person with the same question finds
  it.
- **Something wrong:** an [issue](https://github.com/lapilli-project/lapilli/issues/new/choose), with a form for a
  rule that replays differently from how it fired, one for a barrier to
  access, and one for anything else.
- **A vulnerability:** privately, as [SECURITY.md](SECURITY.md) says; never
  in an issue or a discussion.

Lapilli has one maintainer and no paid support: answers come as time
allows. Please keep tokens, webhook URLs, real hostnames and incident
titles out of what you post.
