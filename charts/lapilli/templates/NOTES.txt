{{- else if $s.signIn.proxyJWT.kind }}

{{- else if $s.userHeader }}

Who people are comes from the proxy's {{ $s.userHeader }} header.
{{- else }}

It signs no one in: keep the Service inside the cluster, or sign people in
(serve.signIn.oidc, serve.signIn.proxyJWT, or serve.userHeader behind a proxy).
{{- end }}
{{- if $s.readOnly }}
It is read-only (serve.readOnly): no one changes anything through the UI or the API.
{{- else if or $s.roles.editors $s.roles.admins }}
Those serve.roles names, as the sign-in names them, change what their role allows; everyone else may only look.
{{- else if $s.everyoneAdmin }}
With serve.everyoneAdmin, everyone who reaches the UI or the API changes anything, as an admin.
{{- else if or $s.signIn.oidc.issuer $s.signIn.proxyJWT.kind }}
With no serve.roles, everyone signed in may only look: name who may change what in serve.roles.
{{- else }}
With no serve.roles, everyone may only look: give roles behind a sign-in
(serve.signIn or serve.userHeader, and serve.roles), or set serve.everyoneAdmin.
{{- end }}

{{- if .Values.serve.changes.enabled }}

  kubectl -n {{ .Release.Namespace }} create configmap {{ include "lapilli.fullname" . }}-changes-paused --from-literal=paused=1
